## File-by-File Audit Tables (Phase A)

Two agents do independent passes over the same files — Claude first, Codex following.
Each agent records findings in its own table. Discrepancies and unique findings from
each pass are reconciled during A.4 (code quality). If both agents flag the same issue,
it gets priority. If only one flags something, it's still logged for review.
